# TCSignIn

Automate daily dropoff and pickup sign-in on [Transparent Classroom](https://www.transparentclassroom.com) using iOS Shortcuts and JavaScript injection.

## Overview

Transparent Classroom sign-in/out involves several steps each morning and afternoon:
1. Navigating to the school's distance dropoff/pickup page
2. Entering your parent PIN
3. Selecting your child from the classroom list
4. Choosing "Dropoff" or "Pickup"
5. Clicking "Sign"
6. Scribbling a signature on the signature pad canvas
7. Clicking "Done"

Because the Transparent Classroom web application uses **Turbo / Hotwire** (DOM updates via fetch/AJAX without full page reloads), a single JavaScript snippet injected via iOS Shortcuts' **"Run JavaScript on Webpage"** action can observe DOM changes, progress through each step, and complete the entire workflow.

The GitHub Pages web app in `/docs` lets parents enter their PIN and child's name to generate the customized JavaScript snippet and URL for their shortcut.

---

## How to Set Up the iOS Shortcut

1. Open the [TCSignIn GitHub Pages site](https://tentose.github.io/TCSignIn/) (or `docs/index.html`).
2. Enter your **PIN** and **Child's Name** (partial, case-insensitive match is supported).
3. Tap **Generate Dropoff Script** (or **Generate Pickup Script**).
4. Open the **Shortcuts** app on your iPhone and tap **+** to create a new shortcut.
5. Add the **"Open URLs"** action and paste the school URL generated by the tool.
6. Add the **"Run JavaScript on Webpage"** action and paste the generated JavaScript snippet.
7. *(Optional)* Add a **"Show Result"** action directly after "Run JavaScript on Webpage" to view the completion status message when executed.
8. Rename the shortcut to "Dropoff" or "Pickup" and tap **Done**.
9. Tap **⋯ > Add to Home Screen** for one-tap access.

---

## Safety Switch (`CLICK_DONE_BUTTON`)

By default, the generated script sets:
```javascript
var CLICK_DONE_BUTTON = false;
```
This allows you to safely test the shortcut without actually submitting an official sign-in/out. The script will enter your PIN, select your child, select the mode, click "Sign", draw the signature on the canvas, and stop right before clicking "Done".

Once you have verified that the shortcut navigates to the signature screen and signs properly, edit the script in your Shortcuts action and change `var CLICK_DONE_BUTTON = false;` to `true`.

## Debugging and Troubleshooting

If the shortcut is not behaving as expected:

### 1. View Error Messages via "Show Result"
Add the **"Show Result"** action immediately following the **"Run JavaScript on Webpage"** action in your shortcut. The action output will display the value returned by `completion(...)`:
- `READY: ...` — All steps up to the final button succeeded (returned when `CLICK_DONE_BUTTON = false`).
- `OK: ...` — All steps including "Done" completed successfully.
- `ERROR: Timed out waiting for the next step...` — The script stalled on a particular step because the expected DOM element was not found within 60 seconds.

### 2. Debug Directly in the Browser Console (Fastest)
1. Open the school's dropoff page in **Safari on your Mac or iPhone**.
2. Open Developer Tools / Web Console.
3. Paste the generated script directly into the console and press **Enter**.
4. You can observe each action log and step transition in real time without needing to run through Shortcuts.

### 3. Remote Web Inspector on iOS
To debug live execution on your iPhone:
1. On iPhone: go to **Settings > Safari > Advanced** and turn on **Web Inspector**.
2. Connect your iPhone to your Mac with a USB cable.
3. On Mac Safari: open **Develop > [Your iPhone Name] > [Transparent Classroom Tab]**.
4. Run the shortcut or inspect the DOM elements, network requests, and console logs.

### 4. Common Issues
- **Child name match**: The script checks child tile `aria-label`, text content, and image `alt` attributes against the lowercase search string. Ensure the name matches at least part of your child's display name.
- **Button label changes**: Transparent Classroom buttons are matched strictly by exact visible text ("Sign in", "Sign", "Done", "Dropoff", "Pickup").
