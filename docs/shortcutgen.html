Transparent Classroom Sign-In Shortcuts

Generate an iOS Shortcut that automatically signs your child in or out on the school's Transparent Classroom dropoff/pickup page.

Heads up: Apple now requires .shortcut files to be cryptographically signed by the Shortcuts app before they can be imported, which isn't possible from a static web page. Downloading below likely won't import successfully on current iOS versions. Use the manual setup page instead — it walks you through building the shortcut yourself and pasting in the generated script.

A case-insensitive partial match is used, so "jam" will match "Jamie L".

How to install

  1. Tap a download button above (best done in Safari on your iPhone).
  2. Open the downloaded .shortcut file (e.g. from the Files app or the download banner) and tap Add Shortcut.
  3. If you see an "Untrusted Shortcut" warning, run the shortcut once, then enable Settings > Shortcuts > Advanced > Allow Untrusted Shortcuts and try importing again.
  4. Add the shortcut to your Home Screen (Shortcuts app > shortcut > ⋯ > Add to Home Screen) for one-tap access.

Your PIN and child's name are embedded directly into the downloaded file and are never sent anywhere — this page runs entirely in your browser.
