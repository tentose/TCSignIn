Transparent Classroom Sign-In Shortcuts

Get a piece of JavaScript you can paste into a Shortcuts action to automatically sign your child in or out on the school's Transparent Classroom dropoff/pickup page.

Apple requires .shortcut files to be signed by the Shortcuts app before they can be imported, so this page can't hand you a ready-made file anymore. Instead, fill in the form below, then follow the instructions to build a tiny shortcut yourself (takes about a minute) and paste in the generated script.

How to build the shortcut

  1. Fill in your PIN and child's name above, then tap Generate Dropoff Script or Generate Pickup Script.
  2. Open the Shortcuts app on your iPhone and tap + to create a new shortcut.
  3. Tap Add Action, search for "Open URLs", and add it. Paste in the URL from step 1 above.
  4. Tap Add Action again, search for "Run JavaScript on Webpage", and add it. Paste in the script from step 2 above.
  5. Tap Add Action once more, search for "Show Result", and add it right after "Run JavaScript on Webpage" — this shows you the status message so you can tell what happened (see Debugging below).
  6. Tap the shortcut's name at the top to rename it (e.g. "Dropoff" or "Pickup"), then tap Done.
  7. Add it to your Home Screen for one-tap access: open the shortcut's settings (⋯) > Add to Home Screen.

Your PIN and child's name are only used to build the script shown above and are never sent anywhere — this page runs entirely in your browser. Once pasted into your own shortcut, only Apple's Shortcuts app and the school's website ever see them.

Safety switch: the generated script has a CLICK_DONE_BUTTON variable near the top, set to false by default. With it off, the shortcut fills in the PIN, child, mode, and signature but stops just before the final "Done" tap, so you can test it safely. Once you've confirmed it works (see Debugging below), edit the pasted script in the Shortcuts action and change it to true so the shortcut completes sign-in/out automatically.

Debugging

  1. Add a "Show Result" action right after "Run JavaScript on Webpage" (see step 5 above). Running the shortcut will now display a message: READY: ... means it got all the way through but stopped before Done (expected while CLICK_DONE_BUTTON is false); OK: ... means it fully signed in/out; ERROR: ... means it got stuck on a specific step — the message tells you which one (e.g. "Timed out waiting for the next step").
  2. If it's stuck, first try running the shortcut again slowly and watch what actually happens on screen (PIN filled in? Child tile selected? Signature drawn?) to see which step it stopped at.
  3. For a much faster debug loop, open the school's page in Safari on your Mac (or iPhone), open Developer Tools / the JavaScript console, paste the script from step 2 above directly into the console, and press Enter. You'll see any errors immediately instead of waiting on Shortcuts.
  4. You can also inspect the live iPhone page from a Mac: enable Settings > Safari > Advanced > Web Inspector on the iPhone, connect it to your Mac via cable, then on the Mac open Safari's Develop menu, select your iPhone, and pick the open tab to see the console and inspect elements while the shortcut runs.
  5. A common cause of failures is the school's website changing its button labels, CSS classes, or page flow — the script matches on visible text like "Sign", "Done", and the child's name, plus a few CSS selectors for the child tiles and signature canvas. If Transparent Classroom updates their site, those matches may need to be regenerated/updated here.
